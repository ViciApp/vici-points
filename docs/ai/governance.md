# Governance

What an agent may do in this repo without asking, what it must ask for, and
which page to update for which kind of change.

## Truth hierarchy

Highest wins on a conflict:

1. The code (`src/**`, `scripts/**`, `Cargo.toml`, `dfx.json`).
2. CI (`.github/workflows/**`).
3. [CODEOWNERS](../../.github/CODEOWNERS): `@antonioventilii` owns everything.
4. `docs/ai/**`.
5. [`AGENTS.md`](../../AGENTS.md).
6. Tool layers (`CLAUDE.md`, `.cursor/rules`, copilot instructions).

On a contradiction, stop and ask instead of guessing.

## Why this repo is sensitive

The minter is the minting account of the VXP ledger on mainnet
(`canister_ids.json`): whatever it mints is new supply. A bug in a cap, a rate
limit or a lock is inflation that cannot be undone. Upgrades restore the whole
state from stable memory, so a type change that does not decode makes the
upgrade trap. Nothing deploys on merge; deploys are manual `npm run deploy:prod`
or `reinstall:*:prod` runs by the owner. A tag `v*` publishes the release
assets (`minter.wasm.gz`, `minter.did`, ledger and index) that vici-app pins
and installs (`VICI_POINTS_VERSION` in its
`scripts/build/download.vici_points.minter.sh`).

## Protected and generated paths

| Path                                                                                   | Why                                                                                 | Rule                                                                            |
| -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `src/minter/minter.did`                                                                | Generated by `npm run did` (candid-extractor on the wasm)                           | Never hand-edit; regenerate and commit with the API change                      |
| `src/minter/src/state.rs`, persisted types in `model.rs`                               | Decoded from stable memory on every upgrade                                         | Ask first; follow [change-persisted-type](./workflows/change-persisted-type.md) |
| `canister_ids.json`                                                                    | Mainnet canister ids                                                                | Ask first                                                                       |
| `dfx.json`, the ledger-suite release in it and in `scripts/download.ledger.sh`         | Which ledger and index wasm get installed                                           | Ask first                                                                       |
| `scripts/build.*.args.sh`                                                              | Init and upgrade arguments, including token name, decimals, fee and minting account | Ask first; see [canister-args](./workflows/canister-args.md)                    |
| `scripts/init.reserves.sh`                                                             | Reserve caps and daily budgets on mainnet                                           | Ask first; numbers are business decisions                                       |
| `.github/workflows/**`, `.github/actions/**`                                           | CI integrity and release assets                                                     | Ask first; `ci(...)` PRs only                                                   |
| `Cargo.toml` `[workspace.lints]`, `clippy.toml`, `rustfmt.toml`, `rust-toolchain.toml` | The lint and format contract                                                        | Ask first; never loosen to get green                                            |
| `Cargo.toml`, `Cargo.lock`, `package.json`, `package-lock.json` dependencies           | New dependencies need the owner's approval                                          | Ask first; see [dependency-bump](./workflows/dependency-bump.md)                |
| `scripts/init.reserves.config.sh`                                                      | Real reserve principals                                                             | Never commit (gitignored)                                                       |
| `.dfx/`, `out/`, `target/`, `.env`, `**/declarations/`, `node_modules/`                | Build and deploy output                                                             | Never commit                                                                    |

## Allowed without asking

- Edit `src/minter/src/services/**`, `api/**`, `guards.rs`, `lib.rs` and
  non-persisted types in `model.rs`, with tests.
- Edit `docs/ai/**`, `AGENTS.md`, `README.md`, `src/minter/README.md`, and
  scripts outside the protected rows above.
- Run `npm ci`, `npm run format`, `npm run lint`, `npm run did`,
  `npm run build`, `cargo test`, and `npm run deploy` against a local replica.
- Push a branch and open a PR.

## Never without an explicit ask

- Merge a PR, enable auto-merge, push to `main`, push a `v*` tag.
- Run anything with `--ic` or `DFX_NETWORK=ic`: `npm run deploy:prod`, any
  `reinstall:*:prod`, `scripts/init.reserves.sh` against mainnet, or
  `dfx canister call` on a mainnet canister.
- Change a number that moves supply: reserve caps, daily budgets, rate-limit
  defaults, `REBALANCE_INTERVAL`, token decimals or fee. Propose, do not pick.
- Remove or rename a Candid method, field or `MinterError` variant: vici-app
  installs and calls the minter, and vici-maker's `FUNDING.md` calls
  `manual_topup_reserve`.
- Add a dependency, a crate to the workspace, a canister or a top-level folder.

## Meta-update map

A PR that changes one of these updates the matching page in the same PR.

| Change                                           | Update                                                                                 |
| ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| New shared function, constant, type or script    | [`reusability.md`](./reusability.md)                                                   |
| New pattern, or an anti-pattern removed or found | [`patterns.md`](./patterns.md)                                                         |
| New file, module or dependency direction         | [`structure.md`](./structure.md) and the code tree in `src/minter/README.md`           |
| New or changed endpoint                          | `src/minter/README.md` API reference, and `minter.did` via `npm run did`               |
| New or changed reserve concept, cap or policy    | `src/minter/README.md` concepts; `TOKENOMICS.md` if the economics change               |
| New test location, helper or command             | [`testing.md`](./testing.md)                                                           |
| New CI job, gate, script or PR convention        | [`pr-and-ci.md`](./pr-and-ci.md)                                                       |
| A recurring kind of change with no recipe yet    | a new page in [`workflows/`](./workflows/) and the index in [`README.md`](./README.md) |
| A policy here                                    | this page, and `AGENTS.md` if the summary changes                                      |
