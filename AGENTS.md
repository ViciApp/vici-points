# AGENTS.md

Entry point for every AI coding agent working in this repository (Claude Code,
Cursor, Codex, Copilot, Aider, ...). Read it before any change. It is short on
purpose; the detail lives in [`docs/ai/`](./docs/ai/README.md).

## 1. What this repo is

`vici-points` is Vici XP (VXP), the gameplay token of Vici: an ICRC-1/2/3
ledger and index (official DFINITY wasm, no code here) plus one custom Rust
canister, the **minter**, which is the ledger's minting account and keeps a set
of reserve accounts topped up under caps and rate limits. The why is in
[`README.md`](./README.md), [`TLDR.md`](./TLDR.md) and
[`TOKENOMICS.md`](./TOKENOMICS.md); the minter's logic and API in
[`src/minter/README.md`](./src/minter/README.md).

- **The minter creates money.** Every change to `src/minter/src/**` is
  reviewed as if it moved funds. Never deploy, reinstall or call a mainnet
  canister (`npm run deploy:prod`, `reinstall:*:prod`, `dfx ... --ic`).
- **State survives upgrades by Candid encoding.** A field added to `State` or
  to a type it holds must decode from the old bytes, or `post_upgrade` traps.
  See [`docs/ai/patterns.md`](./docs/ai/patterns.md#stable-state).
- **Do not hand-edit** `src/minter/minter.did`: it is generated by
  `npm run did`. See [`docs/ai/governance.md`](./docs/ai/governance.md).

## 2. Commands

```bash
npm ci                         # prettier and plugins
npm run format                 # prettier, cargo sort, cargo fmt (nightly), shfmt
npm run lint                   # prettier check + scripts/lint.sh (what CI runs)
cargo test --locked -p minter  # unit tests; CI does not run them, you must
npm run did                    # rebuild minter.did after an API change
npm run build                  # minter wasm + downloaded ledger/index wasm
```

Tool versions and the tools `lint` and `format` need (cargo-sort, shfmt,
shellcheck, zizmor, yq, candid-extractor) are pinned in
[`dev-tools.json`](./dev-tools.json); `scripts/setup <tool>` installs one.

## 3. Layout

```
src/minter/src/lib.rs        lifecycle hooks (init, pre/post upgrade), export_candid!
src/minter/src/api/          Candid endpoints: admin/ (updates), query/ (queries)
src/minter/src/services/     reserve.rs pure rules, rebalance.rs, ledger.rs, timer.rs
src/minter/src/model.rs      domain and Candid types, MinterError
src/minter/src/state.rs      the one STATE and its stable-memory save/restore
src/minter/src/guards.rs     caller guards
scripts/                     build, lint, format, canister init args, reserve setup
```

Full taxonomy and dependency direction: [`docs/ai/structure.md`](./docs/ai/structure.md).

## 4. The standard

Every change follows the universal standard in
[`AntonioVentilii/officina` `standards/code.md`](https://github.com/AntonioVentilii/officina/blob/main/standards/code.md).
It is not repeated here. What this repo adds:

1. **Pure rules stay pure.** Validation and amount computation live in
   `services/reserve.rs` and take plain values: no `STATE`, no `time()`, no
   ledger calls. That is what the unit tests cover.
2. **Never hold a `STATE` borrow across an `await`.** Read a snapshot, release,
   call the ledger, then commit in a new borrow.
3. **Every mint takes the per-reserve lock** (`reserve_mint_inflight`) and
   releases it on every exit path. See [the mint pattern](./docs/ai/patterns.md#mint).
4. **Every endpoint has a guard**: `caller_is_controller` for writes,
   `caller_is_not_anonymous` for reads and previews.
5. **Errors are `MinterError` variants**, returned through a named result enum
   per endpoint (`lint.did.sh` rejects `Result` and `Result_N` in the `.did`).
6. **Clippy is pedantic and warnings are errors.** A lint that must stay off at
   one site gets `#[expect(lint)]` with a reason comment, never `#[allow]`
   (`allow_attributes` is denied). Size limits per function and per file,
   and no `unwrap` / `expect` / `panic!` outside tests, are part of
   `npm run lint`; existing excess is
   pinned and may only shrink. See
   [the quality gate](./docs/ai/pr-and-ci.md#quality-gate).
7. **Time is nanoseconds, named `_ns`**, from `ic_cdk::api::time()` read once
   per operation.

## 6. Governance

- **Truth hierarchy**, highest wins: the code, then CI
  (`.github/workflows/**`), then [CODEOWNERS](./.github/CODEOWNERS), then
  `docs/ai/**`, then this file, then tool layers (`CLAUDE.md`,
  `.cursor/rules`, copilot instructions). On a contradiction, stop and ask.
- **Meta-update rule.** A PR that adds a pattern, a shared helper, a constant,
  an endpoint, a persisted field, a script, a policy or a workflow updates the
  matching `docs/ai/**` page in the same PR. The map of which page owns what is
  in [`docs/ai/governance.md`](./docs/ai/governance.md#meta-update-map).
